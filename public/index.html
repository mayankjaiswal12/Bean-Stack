JSON Format

Give this structure to ChatGPT along with your recipes and ask it to convert them into this JSON format. Only name is required — everything else is optional and will default sensibly. 

[
  {
    "name": "Recipe name (required)",
    "bean": "Bean name",
    "brewer": "V60 / AeroPress / Chemex / etc",
    "coffee": 18,
    "water": 300,
    "temp": 94,
    "grind": "e.g. medium-fine, 24 clicks",
    "rating": 5,
    "steps": [
      {
        "type": "Pour",
        "label": "Bloom",
        "color": "#fde68F",
        "startMin": 0,
        "startSec": 0,
        "durMin": 0,
        "durSec": 30,
        "weight": 40,
        "notes": "Saturate grounds evenly"
      }
    ]
  }
]

Tip: Ask ChatGPT: "Convert my coffee recipes into this exact JSON array format: [paste the structure above], one object per recipe, times split into minutes/seconds."

Notes: type should match one of your step types (Pour, Wait, Swirl, Stir, Bloom, or any custom type you've added) — unrecognized types are still imported, just won't have a matching color preset. color is optional (hex code); if omitted it defaults to your Pour color. weight is grams, omit or set null if not applicable.
