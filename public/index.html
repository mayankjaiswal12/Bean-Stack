    JSON format

    Use a single recipe object or an array. Only name is required. Step weights are cumulative grams. Start and duration are expressed separately.

    {
  "name": "My V60 Recipe",
  "bean": "Ethiopia Yirgacheffe",
  "brewer": "V60",
  "coffee": 15,
  "water": 250,
  "temp": 94,
  "rating": 5,
  "steps": [
    {"type":"Bloom","label":"Bloom","startMin":0,"startSec":0,
     "durMin":0,"durSec":40,"weight":45,"notes":"Wet all grounds"}
  ]
}
